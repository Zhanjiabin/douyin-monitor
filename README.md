# 观潮 · 抖音内容情报与增长分析平台

基于 [zouzibo-tech/douyin-playcount-monitor](https://github.com/zouzibo-tech/douyin-playcount-monitor) 的采集内核进行扩展。保留 Playwright 浏览器响应监听、SQLite 历史快照、增量计算、定时任务、Excel 导出和本地运行模式。

## 当前版本

本分支第一阶段以**真实数据接入 + 信息架构重构**为目标：

- 数据总览：真实合集总播放、日增、监控数量、停涨与数据健康状态。
- 账号矩阵：从已采集合集归并作者维度，显示账号作品覆盖及表现。
- 视频监控：展示已采集合集内分集的播放、点赞、评论、收藏及历史增量。
- 合集监控：按合集维度展示官方总播放、分集求和校验、集数与更新状态。
- 赛道情报：对已采集作品标题做轻量关键词归纳；样本不足时明确提示。
- AI 起号工作台：根据本地真实采集样本生成可解释的规则型诊断草案。当前不调用外部 LLM，不将规则建议冒充模型生成。
- 预警中心：采集失败、数据校验差异、停涨与新采集状态。

## 数据边界

上游采集能力主要覆盖**发布在抖音合集中的视频**。平台不公开或本工具未采集的曝光、完播率、推荐流量来源、非合集视频真实播放量，不会伪造或推算为真实数据。账号矩阵目前是由已识别作者归并而来，并不等于已具备完整的账号作品自动发现能力。关键词赛道归纳也只针对本地已采样本。

## 运行

沿用上游要求：Windows 10/11、系统 Edge；源码运行：

```bash
pip install playwright openpyxl
python -m playwright install chromium
python src/app.py
```

程序只监听 `127.0.0.1`。请遵守抖音平台条款并控制采集频率。
