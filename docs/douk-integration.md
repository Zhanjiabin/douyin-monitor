# TikTokDownloader 集成

入口：启动观潮后打开 `http://127.0.0.1:8795/studio`，或从作品监控侧栏进入「采集工作台」。作品详情中的「解析 / 下载 / 补采」可直接带入作品 ID。

## 安装和运行

当前工作区已安装引擎并同步本机采集浏览器的抖音登录。新环境使用 Python 3.12 或以上版本执行：

```powershell
python -m pip install -r requirements.txt
python scripts/setup_douk.py
python src/app.py
```

安装脚本创建 `.douk-venv`，安装上游依赖并生成表单功能清单。主项目和上游同名的 `src` 包通过独立进程隔离。直播录制需要 FFmpeg；可使用 PATH 中的程序，也可以在引擎设置中指定路径。

完整上游源码在 `vendor/TikTokDownloader`，版本 5.8，提交 `e327b9549d284a8b1613566f949fe2dbb8a6c2a1`，保留原始 GPL-3.0 许可证。版本信息和第三方说明在 `integrations/`。适配修改在 `scripts/douk_worker.py`，未直接修改上游源码。

## 功能覆盖

| 平台 | 已接入入口 |
| --- | --- |
| 抖音 | 分享解析、作品详情、账号发布/喜欢作品、合集、直播地址、评论、评论回复 |
| 抖音搜索 | 综合、视频、用户、直播 |
| 抖音其他 | 账号资料、热榜、我的收藏作品、收藏夹列表、收藏夹作品、收藏合集、收藏音乐、收藏短剧列表 |
| TikTok | 分享解析、作品详情、账号发布/喜欢作品、合集、直播地址、账号资料、账号合集列表 |

共 19 个抖音入口、7 个 TikTok 入口。平台返回哪些内容取决于会话、作品可见范围及接口状态。TikTok 需自行配置相应 Cookie 和网络环境；不会复制抖音登录作为 TikTok 登录。

工作台支持：

- 多行链接 / ID、TXT 导入、账号及合集预设；预设的范围和日期随每条任务生效，修改表单参数后采用表单值。
- 串行任务队列、批次进度、取消、重试、逐项失败信息、部分结果保留。
- 上游媒体下载器处理视频、图集、实况、封面、配乐、最高画质选项、断点续传和去重；下载文件在页面中打开或下载。
- 收藏音乐下载、直播拉流地址查询与指定时长录制。直播必须先查询，再从返回地址选择，最长录制一小时。
- 剪贴板监听：用户主动开启并授权读取后，仅在当前页面获得焦点时读取新链接并提交下载。
- 下载命名、文件夹、大小限制、页数、重试、代理等设置；高级设置包含上游配置项。下载根目录固定在项目输出目录，任意外部命令配置 `run_command` 不执行。
- 下载记录持久化；结果列表可重置对应作品的去重记录，重置不删除已下载文件。
- 结果搜索、分页、原始数据详情、Excel / CSV / JSON 导出；上游媒体任务的数据记录格式也可在高级设置选择 SQLite。
- 抖音结果显式加入原监控，保留原账号分组。头像与作品封面按需缓存；TikTok 结果保留在工作台，不混入抖音指标。

上游现有代码未开放的功能没有假接入：旧 Web UI 重构中（本项目另建工作台）；TikTok 评论、话题下载和第三方 TikTok 原画下载菜单未实现或被禁用。语音转写和 AI 视频拆解不是该项目提供的能力，本次未把作品标题当成视频逐字稿。

适配层修正上游 TikTok 合集缺少平台参数、合集链接三项返回值和直播请求模型不匹配的问题。原始上游源码也保留其独立运行入口；本项目服务继续仅监听本机地址。

## 播放量与监控数据

「补采缺失播放」会为监控中缺失播放量的作品调用 DouK 详情接口。接口存在 `play_count` 字段并不代表对所有视频返回有效计数。只有正数被写为有效播放量；0 / 缺失保持未知，不能解读为真实零播放。

DouK 观测单独记录在 `external_video_observations`，补查结果记录在 `external_playback_checks`。已有合集有效播放不会被缺失响应覆盖；不同来源不能直接拼成有效增长。页面显示来源、采集日和缺失原因。

2026-11-04 实测作品 `7703151458754472787`：下载的视频长 390.047 秒、96,469,548 字节，但详情接口没有有效播放量。账号分页实测安夏返回 46 条作品，不能据此保证主页声明的全部作品均可访问。

同日全量补查任务 `d4f39e8dbf0948e1` 已完成 190 / 190 条，无请求错误，190 条详情与互动观测入库，新增有效播放量 0 条。监控仍为 644 条作品、454 条有效播放样本、190 条缺失；缺失原因已标为 DouK 已取得详情但未返回有效播放数。这里的「完成」指补查执行完成，不代表播放量已补齐。

## 文件与登录

- `data/douk/settings.json`：本机引擎设置和 Cookie，不入版本控制。
- `data/douk/jobs/`：请求、进度、结果和日志；只在本机保存。
- `data/douk/DouK-Downloader.db`：上游去重和配置数据库。
- `output/downloads/`：媒体、直播及导出元数据。
- `data/media/`：监控头像和封面。

界面不会回显已保存的 Cookie；结果及导出移除认证字段。同步登录只读取本项目 `.browser_profile`，不会扫描其他浏览器。登录过期可重新登录采集浏览器后点击同步。

## 验证

```powershell
python -m unittest discover -s tests -v
python scripts/check_studio.py
python scripts/check_screen.py
node --check src/webui/studio.js
```

36 项自动测试包含原有监控回归、来源优先级、缺失值处理、平台隔离、路径边界、认证信息清理及导出公式转义。工作台验收使用独立数据库和队列，检查全部 26 个表单、分页搜索、原始数据、三种导出、批量提交、取消重试、设置及窄屏布局，不修改真实数据。

真实网络已验证抖音详情、账号分页、评论、关键词视频搜索、账号资料、四类热榜（本次返回 201 条）和视频下载。未使用用户未提供的 TikTok 登录，未对全部收藏类型或正在直播的流逐项网络验收；这些入口已接线，但可用性仍以实际返回为准。
