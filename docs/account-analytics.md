# 作品更新历史与账号统计

工作台、作品监控、账号作品弹窗、内容研究与发现作品列表均显示数据更新时间。详情顶部的「上次数据更新」来自作品最近一条有效指标观测，不是页面刷新时间。下载文件、采集评论或未返回任何指标的响应不会使该时间前移。

## 每次更新的历史

作品详情和内容研究页面均提供「历史数据」标签：

- 更新时间统一使用北京时间，展示到秒；数据库保存毫秒和时区。
- 每次成功取得指标都追加记录，包含播放、点赞、评论、收藏和分享。缺失字段保持空值，不能用上次结果冒充本次返回。
- 保留来源和播放口径，播放变化对比前一次同来源、同口径的有效播放记录。负值如实展示，表示计数回退，不计算为增长。
- 最新记录在前；可选择每页条数、翻页和跳转指定页。完整整数用于核对小幅变化。
- 原有按日快照继续用于原有业务；新增 `video_metric_events` 独立保存逐次历史。升级时只回填此前仍保留的日快照，标记「旧日快照」。过去已覆盖的中间值无法恢复。
- TikHub 请求流水作为去重键，重复导入同一响应不重复留档。新请求即便值不变也会保留，表示在该时刻重新观测过。

## 数据统计 `/analytics`

入口位于侧栏「数据统计」，也可从工作台账号卡片或账号弹窗进入。每次只统计一个监控账号，包括暂停账号。未指定账号时默认选择监控中的自有账号，再依次选择其他监控账号。账号、7/30/90 天观测周期、作品关键词须点击「搜索」才应用；「重置」恢复默认条件并重新查询。

| 维度 | 图表 | 明细 |
| --- | --- | --- |
| 账号趋势 | 观测总量折线、可比作品日增柱图 | 每天五项指标、选定指标的日增、有效和可比作品数、更新时间 |
| 作品表现 | 选定指标前十排行、互动构成 | 每条作品的发布时间、五项指标和更新时间，可打开作品详情 |
| 发布分析 | 星期 × 小时发布热力图、各时段播放中位数 | 每个发布时段的作品数、已知播放样本数与中位数 |

指标可切换播放、点赞、评论、收藏和分享。图表与明细展示切换不发起采集；「刷新统计」只重新读本地库。导出当前维度的全部筛选结果为 CSV，不限当前分页。表格保留底部分页与跳页，只有内容区域滚动。

## 统计口径

1. 观测周期筛选**采集日期**，不限制作品发布年龄。单日同作品取该指标最后一次有效值，不因一天内多次刷新而重复累加。周期内最新值取最后一次有效观测；整个周期未取得的字段显示为空。
2. 日增只比较相邻两天都观测到的同一作品、同一来源、同一口径。缺一天、来源或口径变化、计数回退都不计入增长。当天未返回播放，不使用前一天的播放冒充当天观测。
3. 观测总量的样本可能逐日变化，因此总量的差值不等于新增。趋势横轴仅显示已有观测区间，中间缺测日期留空；少于两天时展示实际数据而非空折线。
4. 发布分析只包含所选周期内发布且已知发布时间的作品，按北京时间分组。播放中位数来自周期内最新观测；作品年龄与样本大小会影响比较，不证明某个时段导致推荐。
5. 互动构成是计数分布，不能相加推算独立用户、完播率或平台推荐权重。不需要创作者后台 Cookie 或流量来源权限。

ECharts 6.0.0 固定版本随项目本地托管，源码来源、Apache 许可证和 NOTICE 保存在 `src/webui/vendor/echarts/`。页面不依赖外部 CDN。

升级前备份 SQLite 和配置，新增表自动迁移，不删除原有作品、快照或配置。现有每日备份会一并包含新增历史表；存储随观测次数增长。
