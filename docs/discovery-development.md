# 发现、趋势与样本比较

目标：按产品计划完成原型、榜单与发现闭环、趋势与对标、公开样本比较，部署现有服务器并提交 GitHub。

## 固定交互

- 「发现」日常入口为作品库、热点榜、选题报告；专项榜单和关键词追踪位于「更多榜单」。
- 顶部横向筛选，明确搜索后生效；修改条件、点词、点账号不隐式查询或收费。
- 重置立即恢复当前视图默认条件并重新搜索缓存，所有日常页面遵循相同行为。
- 作品库搜索、筛选、排序、分页读取已保存的数据库；同步整轮榜单时预览请求数，专项榜单仍默认单页。
- 共用任务账本、额度与错误处理；播放统计保持单作品默认，批量默认关闭。
- 正文可读、紧凑表格、封面、底部分页（总数、每页条数、指定页码跳转）。
- 详情仅一层，保留返回状态；作品评论采集、更新、下载原位操作。
- 没有权限或供应商未返回的指标保留未知，热度、窗口播放、累计播放不混淆。

## 日常使用

### AI 创作方向（2026-11-07）

`/discover` 默认围绕 AI 漫剧、AI 短剧、AI 萌宠 IP、AI 大片查找作品。只凭平台“AI 原生影像”分类或搜索词不能证明每条结果相关，因此在标题、标签和明确的 IP 名称上做可解释匹配，默认排除教程、工具和营销等无关内容。规则不是 AI 生成鉴定，未识别或综合内容仍保存在数据库，可选择“全部已存内容”查看；不改写平台原始分类。筛选仍需点击搜索，重置直接重新搜索，导出遵守相同范围。

“定向找作品”提供四个方向的可编辑关键词，调用 TikHub 视频搜索 V3，每次一个词、一页。选方向、选关键词、打开参考作品都不会发付费请求；预览后确认才创建任务。修改条件使旧预览失效。返回结果进入原有持久库，保留查询范围、原始字段和采集时间。作品累计播放和榜单窗口播放分别展示，未返回的数据保持未知。

实测单次搜索可返回约 1,000 条作品，不能把页面大小当成返回上限。完整作品与回执先持久保存，再对最多 12 条作品的封面和头像做预缓存，其余保留供应商图片地址；已有本机图片通过只读查找复用。图片失败不使已保存结果失败，也不重发付费请求。

“IP 参考”保存渡骸、南僵、猫子柒、云咪的作者原作链接，便于先看内容再找同类。南僵目前核对的是作者在哔哩哔哩的原作，不伪造抖音作品 ID。参考入口没有虚构播放量；支持用已经核实的抖音作品逐条采集并加入监控，不按作者昵称猜测身份。

“采集计划”集中管理 TikHub 关键词搜索计划，并保留综合榜单和报告的设置入口。创建搜索计划默认暂停，启用后才按设置的间隔执行；每轮一页，复用现有额度、版本失效、任务记录和防重复执行机制。本次升级不自动开启额外的付费关键词计划，也不改变既有综合榜单计划。

“内容报告”只使用已存的相关作品，展示四方向覆盖、按已返回点赞挑选的拆解样本、标题结构、共同标签、原作和采集时间。不再将无关社会热点套成 AI 创意草案，也不将搜索序位或滚动窗口播放变化说成实际播放增长。拆解提示是方向性的观察问题，不冒充已经观看原片后的剧情分析。自动日报、周报也使用此范围，生成和导出不调用付费接口或大模型。新报告 ID 增加 `-ai` 后缀，旧综合报告继续保留；历史日期不会被今天的数据替换。

### 综合榜单与报告

`/discover` 提供统一作品库、热点榜和选题报告。默认从已保存的 TikHub 记录查询，Pro 历史缓存保留但不混入默认发现结果。作品 ID 去重，同时记录它来自哪些榜单、每轮的排名、指标、时间与采集范围。顶部条件在点击搜索后应用，重置立即重新搜索；热点「用于搜索」只填入条件，不暗中应用过滤。详情可查看全部返回字段、原视频、下载、加入监控和历次观测。

「同步榜单」一次安排三个有界任务：综合视频榜、近七天热点总榜、实时热榜。视频分类默认选择 AI 原生影像、二次元、剧情，支持修改。每个总榜最多五页、每页请求 20 条；实时热榜一次返回整榜。按默认五页计算，每轮最多 11 次请求、基础价约 0.011 USD；每天两轮、30 天约 0.66 USD，实际数据量和账单以供应商为准。分类作为同一视频请求的筛选范围，不为每个分类另发一组请求；它不代表返回作品已完成逐条题材识别。

「自动更新」可设置每天 1–6 个北京时间、页数、视频分类、是否抓取两个热点源、日报/周报及报告时间。默认模板为 08:00/20:00 同步，21:00 日报、每周一 21:00 生成上周报告。启用计划受现有全局每日和单任务限额约束，不会开启批量视频统计。修改或暂停使排队中的旧版本失效，每页请求前重新检查；重启仅处理最近到期时段，已认领的失败时段不重试。达到末页或空页提前停止，不继续消耗剩余页数。

报告完全从本地数据库生成，不调用 TikHub 或大模型。日报覆盖选择日期截至生成时刻，周报覆盖结束日期向前七天；自动周报使用上周一到周日。与采集重叠时等待本轮完成再出报告。报告按日期持久保存，支持重新生成和下载独立 HTML。内容包含采集概览、新收录作品、同范围排名变化、标题结构与重复标签、低粉高赞样本、参考作品，以及明确标为草案的创意方向。创意引用的参考作品仅用于学习形式，不冒充与热点相关；供应商标为不可发布的话题不生成创意草案。

热点总榜的当天范围实测为空，近七天范围可用；实时热榜可以返回当前榜单，因此主界面热点默认实时热榜。跨来源不比较热度大小或排名，历史变化只对同一来源、相同窗口和分类范围计算。首轮不显示虚构涨幅；没有采集的日期显示未知。榜单播放为原窗口口径，不写成作品累计播放。标签播放中位数按同一榜单和采集范围分组，点赞/粉丝只作为发现研究样本的比值。

供应商未提供名次字段时，界面以返回页码和顺序记录「榜内序位」，原始字段仍可查看。采集范围标签不冒充逐条内容分类。

### 专项榜单工具

独立的作品发现和关键词工具继续保留如下。

2026-11-04 按用户选择切回 TikHub：作品发现默认「低粉爆款 → AI 原生影像（643）」，热点默认「上升热点」，相关作品进入 TikHub 关键词搜索。新版不沿用旧 Pro 默认查询的浏览器状态。搜索和重置均只读缓存；点击抓取最新预览并确认后才请求供应商，默认一页，每页请求 20 条，不保证每页都有 20 条有效作品。原生搜索、热榜和下载保留为手动工具，不删除既有缓存，也不自动迁移或开启收费定时计划。

当日通过 TikHub 免费端点信息接口核对：低粉爆款、高完播/点赞/涨粉率、上升热点、话题/搜索飙升基础价均为 **0.001 USD/请求**；视频搜索 V3 为 **0.01 USD/请求**；单关键词趋势为 **0.003 USD/请求**。榜单每翻一页算一次请求，同一查询读取本地缓存不增加请求。不同榜单、分类、页数和更新轮次相乘；作品详情、播放刷新等是另外的请求。此为当日标价，后续以供应商价格及实际账单为准。[端点价格查询](https://docs.tikhub.io/186826054e0)、[计费公式与美元单位](https://docs.tikhub.io/186826052e0)。

Pro 搜索、实时热榜、已核实采集记录加入监控，以及原生解析下载均不消耗 TikHub 额度。普通抖音登录由既有 CookieBridge 同步，不需要创作者后台授权。TikHub 专门榜单、关键词指数、画像及缺失播放统计仍按需使用，执行前明确确认。公开搜索没有返回的播放量保持未知；需要时再逐条更新播放。

搜索原生适配器修正了上游分页计数与请求数量不一致造成的跳页，复用平台返回游标；同时限制总数与每词数量，禁止抓取重复作品超过上限。采集缓存不自动订阅作者，下载也不自动把未监控作者加入工作台。加入监控时保留原始观测日期，不将缓存数据冒充刚刚刷新的数据。

1. 在「发现 → 作品发现」选择榜单、平台分类、周期和关键词，点击搜索读取缓存。点击抓取最新核对请求数。手动选择 Pro 时才显示创作方向、采集数量和原生搜索排序。
2. 发现结果可直接查看文案、打开原视频；选中作品后加入监控。加入时逐条请求 App 作品详情，核对作品 ID 和作者 ID 后导入工作台，不按昵称猜测作者。
3. 在热点趋势选择上升热点、话题飙升、搜索飙升或行业趋势。趋势图和数据表均可查看，导出不产生供应商请求。
4. 添加追踪关键词后，查看趋势、相关作品或设置更新计划。关键词热度需在「设置 → 接口连接」单独许可。此专用接口虽然供应商名称含 multi，本产品始终只传一个词；不会启用批量视频统计。
5. 定时更新默认关闭，可设 1/6/12/24 小时间隔。每轮一页，关键词与行业趋势查询最近七个完整日期；暂停或删除会阻止排队中的旧计划继续收费，删除追踪词也会暂停相应关键词计划。任务记录统一在采集中心查看。
6. 账号详情的「粉丝画像」按需查询性别、年龄、地域、兴趣等公开维度；占比与 TGI 分开呈现。作品详情的「样本对比」列出实际参与比较的作品，样本不足五条不计算表现倍数。

## 数据口径

- 榜单 `play_cnt` 保存为榜单播放，不写入作品累计播放历史。关键词搜索返回的 `index` 只是指数，不能当作播放量。
- 高完播/点赞/涨粉榜没有返回的比率留空，不从排名反推比率。平台分类来自已核验的分类接口，分类不等于自定义题材识别。
- 行业趋势实测返回 `rate`，供应商未注明单位，因此展示指标原值，不冒充播放或发布数量。
- 曲线保留真实零值；缺失值不补零、不跨缺口连线。公开画像的 TGI 为指数，只有分布值转成百分比。
- 缓存保留查询条件、采集时间、来源、请求回执及部分失败；无有效响应不覆盖上次成功数据。取消和接口错误均不自动重发。
